## 2024-06-04 - Path Traversal Vulnerability in `Path.Combine`
**Vulnerability:** A path traversal vulnerability existed in `ConversionService.BuildOutputPath` where user input (`fileName`) was directly passed to `System.IO.Path.Combine`. If the user provided a string like `../../../etc/passwd` or `C:\Windows\System32\cmd.exe`, `Path.Combine` would overwrite the base directory and return the malicious path, potentially allowing an attacker to write files (`.vsdx`) to arbitrary locations on the file system.
**Learning:** `System.IO.Path.Combine` in .NET does not inherently sanitize inputs or guarantee that the resulting path is a sub-directory of the first argument. If subsequent arguments start with a root directory separator or drive letter, they become the root of the resulting path.
**Prevention:** Always strictly sanitize untrusted filenames before appending them to a directory path. Strip directory traversal sequences, normalize slash characters, and enforce extraction of just the final file name using `Path.GetFileName()`. Also, provide a secure default in case the sanitized input becomes empty or null.
