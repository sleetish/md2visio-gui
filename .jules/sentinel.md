## 2024-05-28 - [Path Traversal]
**Vulnerability:** A path traversal vulnerability existed in `md2visio.GUI/Services/ConversionService.cs` when constructing output file paths. The `fileName` parameter was directly concatenated with `outputDir` using `Path.Combine()`. If `fileName` contained malicious path traversal sequences (e.g., `../../../etc/passwd`), it could override the `outputDir` and write the output file to an arbitrary location on the filesystem.
**Learning:** `Path.Combine` in .NET does not automatically sanitize its arguments. If the second argument is an absolute path or contains path traversal sequences, it overrides the base path.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize cross-platform slashes (`.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `Path.GetFileName()`, as `GetFileName()` alone may be insufficient for mixed slashes. Additionally, handle the edge case where the sanitized result is empty by providing a safe default string.
