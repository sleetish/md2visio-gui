## 2024-03-24 - [Path Traversal]
**Vulnerability:** The `BuildOutputPath` method in `md2visio.GUI/Services/ConversionService.cs` combines an output directory with a user-provided file name (`fileName`) without sanitizing it. This allows directory traversal via input like `../../../output.vsdx`, letting an attacker write files to arbitrary locations outside the intended output directory.
**Learning:** `Path.Combine` doesn't sanitize cross-platform path separators and traversal tokens (`../`) automatically. When a user input forms a component of an output path, failing to normalize it and strip directory components allows malicious traversal.
**Prevention:** Always sanitize user-provided filename components to prevent path traversal vulnerabilities. Normalize cross-platform slashes (`.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()` or `System.IO.Path.GetFileNameWithoutExtension()`, as these methods alone may be insufficient for mixed slashes. Always handle the edge case where the sanitized result is empty by providing a safe default string (e.g., 'output' or 'default').
