## 2024-06-01 - Path Traversal Vulnerability in GUI Path.Combine
**Vulnerability:** The application was passing an unsanitized `fileName` parameter from user input directly to `Path.Combine` in `ConversionService.BuildOutputPath`. An attacker could exploit this by using path traversal characters (e.g., `..\..\..\`) to write output `.vsdx` files to arbitrary locations on the file system, potentially overwriting critical files or gaining unauthorized access if the application is run with elevated privileges.
**Learning:** `Path.Combine` does not automatically sanitize its arguments. If the second argument is an absolute path or contains path traversal sequences, it can override the base path or navigate outside the intended directory structure. The GUI text box for the filename allowed arbitrary input.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()` to extract only the filename. Always handle the edge case where the sanitized result is empty by providing a safe default string (e.g., "output").
