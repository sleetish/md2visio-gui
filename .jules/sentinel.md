## 2024-05-24 - Path Traversal via Path.Combine
**Vulnerability:** Path traversal vulnerability in `ConversionService.BuildOutputPath` where an attacker could provide an absolute path or path traversal sequence (`..\..\evil.vsdx`) as `fileName` to `Path.Combine(outputDir, fileName)`, breaking out of the `outputDir` directory.
**Learning:** `Path.Combine` has a subtle behavior in .NET where if the second argument is an absolute path or starts with a root directory separator, it overrides the base path entirely. Furthermore, simply checking file names is insufficient without handling cross-platform directory separators.
**Prevention:** Always sanitize user-provided file names. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `Path.GetFileName()` or `Path.GetFileNameWithoutExtension()`, and handle edge cases where the sanitized result is empty by providing a safe default string (e.g., "output").
