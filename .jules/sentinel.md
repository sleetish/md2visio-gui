## 2024-05-21 - Path Traversal Vulnerability in .NET Path.Combine
**Vulnerability:** Path traversal vulnerability due to using user-supplied file names directly with `Path.Combine`. In .NET, if the second argument to `Path.Combine` is an absolute path or contains path traversal sequences, it can override the base path or navigate out of the intended directory.
**Learning:** `Path.Combine` does not automatically sanitize its arguments. Furthermore, when mixed slashes (`/` and `\`) are present, standard methods like `Path.GetFileName()` might not work effectively across all platforms.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()`. Always handle the edge case where the sanitized result is empty by providing a safe default string (e.g., 'output' or 'default').
