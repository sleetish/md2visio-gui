## 2026-04-09 - Path Traversal and Shell Execution Fixes
**Vulnerability:** Path traversal existed in `ConversionService.cs` where the user-provided filename could traverse directories via `Path.Combine`. In `MainForm.cs`, untrusted directories were passed to `Process.Start` with `UseShellExecute=true`, opening the door to shell execution. Links from LinkLabel were opened without validating the URL scheme.
**Learning:** `Path.Combine` doesn't sanitize inputs, meaning if an absolute path or relative path with `..` is passed as the second argument, it overrides the base path. `UseShellExecute = true` can allow unexpected shell interpretation of untrusted strings.
**Prevention:** Normalize cross-platform slashes and apply `Path.GetFileName()` to extract just the file name, followed by providing a safe fallback if empty. Use `explorer.exe` with `UseShellExecute=false` and quoted arguments when opening directories, and use `Uri.TryCreate` to ensure safe URL schemes before passing to `Process.Start`.
