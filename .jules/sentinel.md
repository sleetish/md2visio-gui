## 2024-06-11 - [Path Traversal in Output Directory]
**Vulnerability:** The application was vulnerable to path traversal and absolute path injection when constructing the output file path. In `md2visio.GUI/Services/ConversionService.cs`, the user-provided `fileName` was directly passed into `Path.Combine(outputDir, fileName)`. In .NET, if the second argument to `Path.Combine` is an absolute path (e.g., `/etc/passwd` or `C:\Windows\System32\cmd.exe`), it overrides the base path entirely. Additionally, directory traversal sequences like `../` could escape the intended output directory.
**Learning:** `Path.Combine` does not automatically sanitize its arguments. Passing unsanitized user input as the second parameter is dangerous because it can be an absolute path or contain traversal sequences, leading to arbitrary file write.
**Prevention:** Always rigorously sanitize user-provided filename components to prevent path traversal vulnerabilities. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()`. Provide a safe default string (e.g., "output") if the sanitized result is empty.
