## 2024-05-18 - Path Traversal in Path.Combine
**Vulnerability:** Path.Combine allows path traversal when the second argument is an absolute path or contains path traversal sequences like `../` or `..\`. In `md2visio.GUI/Services/ConversionService.cs`, a user-provided `fileName` was appended to an `outputDir` using `Path.Combine` without sanitization, leading to arbitrary file write (saving `.vsdx` files outside the designated output directory).
**Learning:** `System.IO.Path.Combine` in .NET does not automatically sanitize inputs and acts as an override if the second string is an absolute root path. Mixed slashes can bypass simple string replacements.
**Prevention:** Always rigorously sanitize untrusted filename components to prevent path traversal vulnerabilities. Normalize cross-platform slashes `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)` before applying `System.IO.Path.GetFileName()`. Always handle the edge case where the sanitized result is empty by providing a safe default string.
