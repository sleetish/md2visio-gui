## 2026-05-14 - Fix Path Traversal in `ConversionService`
**Vulnerability:** The `BuildOutputPath` method in `md2visio.GUI/Services/ConversionService.cs` used `Path.Combine(outputDir, fileName)` where `fileName` was directly taken from user input without sanitization. This allows for path traversal vulnerabilities (e.g., passing `../../etc/passwd` as the filename could overwrite files outside the intended directory).
**Learning:** `System.IO.Path.Combine` does not automatically sanitize its arguments. If the second argument contains path traversal sequences or is an absolute path, it can override the base path or navigate outside the intended directory structure.
**Prevention:** Always sanitize user-provided filename components to prevent path traversal vulnerabilities. Normalize cross-platform slashes (`.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()`. Always handle the edge case where the sanitized result is empty by providing a safe default string.
