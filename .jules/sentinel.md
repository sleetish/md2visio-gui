## 2025-02-27 - [Command Execution] Prevent Process.Start Vulnerabilities
**Vulnerability:** The application used `Process.Start` with `UseShellExecute = true` passing unvalidated user-provided data directly. For URLs (`authorLabel.LinkClicked`), it directly passed the link data. For directories (`OnOpenOutputClick`), it directly passed the output directory string to `Process.Start`. This can lead to arbitrary code execution if an attacker can control the input string.
**Learning:** `Process.Start` with `UseShellExecute = true` acts like typing the string into the "Run" dialog in Windows, allowing execution of arbitrary executables, files, or protocols. `UseShellExecute = false` is safer but still requires careful handling.
**Prevention:** For opening URLs, validate the URL scheme via `Uri.TryCreate` to ensure it only allows `http` and `https`. For opening directories, use `explorer.exe` with `UseShellExecute = false`, normalize the path with `Path.GetFullPath`, trim trailing backslashes to avoid escaping the closing quote, and enclose the path in double quotes within the `Arguments` property.
