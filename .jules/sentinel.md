## 2024-05-18 - Prevent Path Traversal in File Writing Methods
**Vulnerability:** Path traversal (Directory Traversal) via `Path.Combine`. In `BuildOutputPath`, the `fileName` parameter was used directly in `Path.Combine(outputDir, fileName)`. If a malicious user or input provided a filename like `../../sensitive/file`, it could override the `outputDir` and write files to arbitrary locations on the file system.
**Learning:** `System.IO.Path.Combine` does not automatically sanitize its arguments. If the second argument is an absolute path or contains path traversal sequences, it can override the base path.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize cross-platform slashes (`Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`), use `Path.GetFileName()` to extract only the final file name component, and handle the edge case where the sanitized result is empty by providing a safe default string (e.g., "output").
