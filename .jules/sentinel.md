## 2024-05-15 - Path Traversal in ConversionService
**Vulnerability:** The `BuildOutputPath` method in `md2visio.GUI/Services/ConversionService.cs` constructed file paths using `Path.Combine(outputDir, fileName)` where `fileName` was directly sourced from user input without sanitization. This allows path traversal (e.g., using `..\..\` to write to arbitrary locations) or absolute path overrides (if `fileName` is an absolute path, `Path.Combine` ignores `outputDir`).
**Learning:** `Path.Combine` in .NET does not sanitize inputs and will yield unsafe paths if either argument contains directory traversal sequences or if the second argument is an absolute path.
**Prevention:** Always normalize slashes (`.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) and apply `Path.GetFileName()` on user-provided file name components before appending them to a base directory with `Path.Combine`. Provide a fallback (e.g., `"output"`) in case the resulting sanitized string is empty.
