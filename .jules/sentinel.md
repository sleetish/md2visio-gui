## 2024-05-29 - Prevent Path Traversal by Sanitizing Path.Combine inputs
**Vulnerability:** The application used user-supplied file names directly in `Path.Combine` without sanitization. An attacker could provide a malicious `fileName` like `../../Windows/System32/evil` to write files to arbitrary locations on the system, leading to arbitrary file write or local privilege escalation.
**Learning:** `System.IO.Path.Combine` does not automatically sanitize its arguments. If the second argument is an absolute path or contains path traversal sequences, it can override the base path.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()`, as these methods alone may be insufficient for mixed slashes. Always handle the edge case where the sanitized result is empty by providing a safe default string (e.g., 'output' or 'default').
