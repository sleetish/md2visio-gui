## 2024-05-18 - Path Traversal Vulnerability in `BuildOutputPath`
**Vulnerability:** Path traversal vulnerability exists in `BuildOutputPath` in `md2visio.GUI/Services/ConversionService.cs`. The `Path.Combine` method is used with `outputDir` and `fileName` without properly sanitizing `fileName`. If `fileName` contains path traversal sequences (e.g., `..\..\`) or is an absolute path (e.g., `C:\secret\`), `Path.Combine` will return a path outside `outputDir` or the absolute path itself.
**Learning:** `System.IO.Path.Combine` in .NET does not sanitize paths. If the second argument is an absolute path or contains path traversal characters, it can override or escape the base path.
**Prevention:** Always normalize and sanitize untrusted input (e.g., cross-platform slashes) and extract just the file name using `Path.GetFileName()` or `Path.GetFileNameWithoutExtension()` before passing it to `Path.Combine`. Also, provide a fallback (e.g., "output") if the sanitized name is empty.
