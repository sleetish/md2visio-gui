## 2024-06-13 - [CRITICAL] Path Traversal in ConversionService
**Vulnerability:** Path Traversal (CWE-22) in `ConversionService.BuildOutputPath`. The unsanitized user-provided `fileName` parameter was passed directly to `Path.Combine(outputDir, fileName)`. Because `Path.Combine` doesn't sanitize paths, an attacker or malicious user could provide a path with directory traversal sequences (e.g., `..\..\Windows\System32\cmd`) or absolute paths, overriding the intended `outputDir` and potentially writing arbitrary files (e.g., `.vsdx`) anywhere on the system, leading to arbitrary file write or overwrite.
**Learning:** `Path.Combine` does not automatically sanitize user input. If the second argument is an absolute path or contains traversal sequences, it overrides the base path.
**Prevention:** Always strictly sanitize filenames provided by users before appending them to directories using `Path.Combine`. Use `Path.GetFileName` after replacing all types of slashes (both `/` and `\`) with `Path.DirectorySeparatorChar` to ensure no path traversal sequences remain. Always fall back to a safe default name (e.g., `"output"`) if the user input becomes empty after sanitization.
