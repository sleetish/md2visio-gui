## 2024-05-24 - Path Traversal bypass via Path.GetFileName
**Vulnerability:** When using `System.IO.Path.GetFileName` or `System.IO.Path.GetFileNameWithoutExtension` on a potentially maliciously constructed user-provided path string on non-Windows platforms, if cross-platform slashes or mixed slashes (e.g., `../` or `..\`) are present in the path string, these functions might not properly extract just the file name, possibly leaving traversal sequences in the resulting string.
**Learning:** `System.IO.Path.GetFileName` and `System.IO.Path.GetFileNameWithoutExtension` do not reliably sanitize user-provided cross-platform paths and can lead to path traversal sequences bypassing checks if the string contains a mix of directory separators like `/` and `\`.
**Prevention:** Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()` or `System.IO.Path.GetFileNameWithoutExtension()`. Always handle the edge case where the sanitized result is empty by providing a safe default string (e.g., "output" or "default").
