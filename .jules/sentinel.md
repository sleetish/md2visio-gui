## 2025-05-06 - Prevent Path Traversal in Path.Combine
**Vulnerability:** A path traversal vulnerability existed in `BuildOutputPath` (`md2visio.GUI/Services/ConversionService.cs`) because user-supplied `fileName` was directly passed to `Path.Combine`. If `fileName` contained an absolute path or relative path traversal sequences (e.g., `../../`), it could override the base directory (`outputDir`), allowing arbitrary file creation outside the intended output directory.
**Learning:** `System.IO.Path.Combine` does not automatically sanitize its arguments. If the second argument is an absolute path, it overrides the first argument entirely.
**Prevention:** Always rigorously sanitize untrusted input before appending it via `Path.Combine`. Normalize directory separators (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) and apply `Path.GetFileName()` to ensure only a valid filename is appended. Also, ensure a safe fallback if the filename evaluates to empty.
