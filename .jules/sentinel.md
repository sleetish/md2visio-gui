## 2024-05-18 - [Path Traversal in Path.Combine]
**Vulnerability:** The `BuildOutputPath` method in `md2visio.GUI/Services/ConversionService.cs` uses `Path.Combine(outputDir, fileName)` where `fileName` is user-controlled. If `fileName` contains path traversal sequences (like `../../../`) or is an absolute path, `Path.Combine` allows overriding the base `outputDir`.
**Learning:** `Path.Combine` does not sanitize or restrict the resulting path to be within the base directory. If the second argument is absolute or uses traversal, it escapes the intended directory. Cross-platform environments also require normalizing both `/` and `\` before extracting the file name.
**Prevention:** Always sanitize user-provided filename components before using them in `Path.Combine`. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) and apply `Path.GetFileName()` to extract only the filename part. Handle empty or whitespace-only results with safe default values.
