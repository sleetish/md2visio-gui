## 2024-05-27 - [Add Maximum Recursion Depth to Prevent Stack Overflow DoS in JSON Parser]
**Vulnerability:** The custom JSON parsing logic in `MmdJsonObj` and `MmdJsonArray` used unbounded recursion to parse nested objects (`{}`) and arrays (`[]`). A maliciously crafted Mermaid file with deeply nested JSON frontmatter could trigger a `StackOverflowException`. In .NET, a `StackOverflowException` cannot be caught and results in an immediate crash of the entire application process, leading to a Denial of Service (DoS) vulnerability.
**Learning:** Even internal or seemingly simple custom parsers must be robust against unbounded input patterns, especially recursion. Standard library features (like try-catch) are ineffective against fatal CLR exceptions like Stack Overflow.
**Prevention:** Always enforce a hardcoded maximum recursion depth limit (e.g., `MAX_DEPTH = 50`) in any custom recursive parsing logic. Throw a standard, catchable exception (like `InvalidOperationException`) when the limit is exceeded.
