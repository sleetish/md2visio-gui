## 2024-05-15 - [Path Traversal in Output Directory]
**Vulnerability:** The application was passing unsanitized user input (`fileName`) directly to `Path.Combine`. In .NET, if the second argument to `Path.Combine` is an absolute path or contains path traversal sequences (`../`), it can override the base path or navigate out of it, allowing files to be written to arbitrary locations.
**Learning:** `Path.Combine` does not automatically sanitize its arguments. Furthermore, cross-platform normalization of slashes is necessary because Windows might not handle forward slashes (`/`) as expected when parsing filenames, and vice versa.
**Prevention:** Always rigorously sanitize user-provided filename components. Normalize cross-platform slashes (e.g., `.Replace('/', Path.DirectorySeparatorChar).Replace('\\', Path.DirectorySeparatorChar)`) before applying `System.IO.Path.GetFileName()`. Always handle the edge case where the sanitized result is empty by providing a safe default string.
