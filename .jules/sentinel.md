## 2024-07-12 - Fix Path Traversal in ConversionService
**Vulnerability:** The `BuildOutputPath` method in `md2visio.GUI/Services/ConversionService.cs` constructed an output file path using `Path.Combine(outputDir, fileName)` where `fileName` was not sanitized. This allowed for path traversal if a user-provided file name contained directory traversal sequences (like `../../`), potentially resulting in files being written outside the intended output directory.
**Learning:** `Path.Combine` in .NET is vulnerable to path traversal because if the second argument contains an absolute path or path traversal sequences, it overrides the base path or resolves to a location outside the base directory. Always sanitize cross-platform path separators and strictly extract the file name before applying `Path.Combine`.
**Prevention:** Normalize cross-platform slashes (`/` and `\`) to `Path.DirectorySeparatorChar` and extract the final file name using `Path.GetFileName`. Provide a fallback (like `"output"`) in case the resulting file name is null or empty.
